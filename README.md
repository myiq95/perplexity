# 서재 — Premium Reader PWA

GitHub Pages에 업로드 후, 모바일 브라우저에서 **홈 화면에 추가**하면 앱처럼 설치됩니다.

## 지원 형식
- TXT (UTF-8 / CP949(EUC-KR) / ANSI 자동 감지)
- DOCX, PDF, EPUB, MD, HTML

## 배포
1. 이 폴더의 모든 파일을 GitHub 저장소에 업로드
2. Settings → Pages → Branch: `main` / 폴더: `/root` 선택
3. 발급된 주소를 모바일에서 열고 홈 화면에 추가

## 핵심 기능
- 서재, 개별 삭제, 진행률 및 이어읽기
- 책갈피, 자동 목차 + 한국 소설 회차 패턴 인식
- 글꼴·크기·줄간격·자간·나이트모드
- 시스템 TTS
- 아일랜드형 아이콘 독 바, 스크롤 시 자동 숨김
- Service Worker 기반 오프라인 캐시
